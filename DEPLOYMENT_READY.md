## 🚀 Deploy in 2-5 Minutes

### **FASTEST: Vercel Direct Deployment**

```bash
# Option A: Using Quick Deploy Script (Windows)
cd d:\Basana_Divya_Portfolio
.\deploy.bat
# Follow prompts and get live URL instantly!

# Option B: Manual Vercel CLI
cd d:\Basana_Divya_Portfolio
npm install -g vercel
vercel --prod
# Answer the prompts, then your URL will appear!
```

### **RECOMMENDED: Vercel + GitHub Integration**

1. **Create GitHub Repository**
   - Go to https://github.com/new
   - Name: `portfolio`
   - Description: "Basana Divya - Portfolio Website"
   - Choose PUBLIC
   - Click "Create repository"

2. **Push Your Code**
   ```bash
   cd d:\Basana_Divya_Portfolio
   git remote set-url origin https://github.com/YOUR_USERNAME/portfolio.git
   git push -u origin main
   ```

3. **Deploy to Vercel**
   - Go to https://vercel.com/import
   - Click "Import Git Repository"
   - Paste: `https://github.com/YOUR_USERNAME/portfolio.git`
   - Click "Import"
   - Click "Deploy"
   - **Your live URL appears in 1-2 minutes!** 🎉

### **ALTERNATIVE: Netlify Deployment**

```bash
cd d:\Basana_Divya_Portfolio
npm install -g netlify-cli
netlify deploy --prod --dir=dist
# Get live URL instantly!
```
